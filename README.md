# RTMU-WebCTC_1.21.1

Minecraft **1.21.1 / NeoForge** port of **WebCTC** — browser-based CTC (Centralized Traffic
Control) for RealTrainMod.

> No more need to build a complicated circuit and IC. Let's make CTC more easily with WebCTC!

- **Original work**: WebCTC by **Kaiz_JP & masa0300** (`org.webctc`)
- **License**: **AGPL-3.0** — inherited from the original WebCTC. See [`LICENSE`](LICENSE).
- **Runtime dependency**: [RealTrainModUnofficial (RTMU)](https://github.com/325-Sunnygo/RealTrainModUnofficial).
  Distributed as a separate jar and loaded alongside RTMU.

## Branches
- `1.21.1` — this branch: the Minecraft 1.21.1 NeoForge port.
- `1.7` — the original WebCTC sources (unchanged).

## Build
This is a **subproject of RTMU** (`compileOnly rootProject`) and is built together with RTMU,
not standalone.
